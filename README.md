# WorkdayStudioSkill

A Claude skill for XSLT in Workday Integrations — Studio, EIB, Core Connectors, PECI/PICOF, Document Transformation.
Auto-triggers on Workday namespaces (wd:, peci:, xtt:, etv:, ps:), .xslt/.xsl files, or any mention of Workday transformations, PECI, or "my XSLT isn't working."

Install

bashgit clone https://github.com/<your-username>/workday-xslt.git ~/.claude/skills/workday-xslt



What's inside

SKILL.md — debugging workflow, namespace cheat sheet, working skeleton
references/namespaces.md — every Workday namespace + when it appears
references/etv-xtt.md — ETV & XTT attribute catalog with examples
references/peci-patterns.md — @peci:isDeleted, sequencing, top-of-stack
references/debugging.md — top 10 broken-XSLT causes
